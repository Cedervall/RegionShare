# RegionShare App Assets

Place the app icon here as either:

- `RegionShare.ico` for direct Windows app and installer usage.
- `RegionShare.png` as source artwork. The packaging script can convert it to `RegionShare.ico` when ImageMagick's `magick` command is installed.

Recommended `.ico` sizes: 16, 32, 48, 64, 128, and 256 pixels.
